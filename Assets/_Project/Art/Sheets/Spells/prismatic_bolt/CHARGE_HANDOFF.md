Four new source sheets: water/water_charge_6f.png, fire/fire_charge_6f.png, wind/wind_charge_6f.png, earth/earth_charge_6f.png. Built-in image generation; original RGBA preserved. Each is 1536x1024, 3 columns by 2 rows, six 512px square cells. Read left to right, top row then bottom. These are source assets, not wired runtime content.

## Presentation

Use one caster-side sprite layer through the existing layered presentation. Start with 0.18–0.20 seconds total, roughly 30–33 FPS, no looping. Keep the gathering point aligned with the projectile's launch point in front of the caster's casting hand/book. Scale the condensed shape smaller than the full projectile; measure painted bounds rather than blindly reusing the core's box size. Maintain consistent pivots across slices.

Frames 1–5 gather and compress. Frame 6 is a rightward release pose, not an empty frame. Start the flight core as frame 6 begins, and crossfade the charge away over that final frame; do not show two full-strength cores. Mirror both together for opposing casters. If this overlap doubles the projectile, omit the final charge frame in the runtime recipe and hand off after frame 5. Preserve the source sheet.

Fit this inside existing anticipation where available rather than stacking another full wait. Flight shedding begins when motion begins. Shift arrival, contact and authoritative hit cue together if release moves later; damage must still synchronize with contact, not charge completion. Charge cleanup must not stop flight or residual particles.

Water gathers droplets; Fire pulls in sparks; Wind tightens air ribbons; Earth locks chips together. Generated sheets contain soft halos despite restrained-glow prompts. Check stage readability and alpha edges, especially Wind, before finalizing opacity. Review the transition in real-time on the actual caster, on both sides. No new engine behaviour or combat changes are requested by this art handoff.
