WHAT CHANGED

  • Currency HUD moved from plain top-centre text to the same gold/relic chip pairing used on the run map and hub — consistent iconography across every screen instead of a bare "Gold: 4 Relics: 1" line.
  • Rows keep the source's gold-rimmed-plate language but get a purchase pulse animation and immediate grey-out when unaffordable, rather than a flat disabled grey with no feedback.
  • Owned upgrades keep the green "Owned" treatment from the source, restyled to the game's success-state green rather than a plain outline.

FOR THE ENGINE

  • Upgrades are one-time purchases: click deducts gold once, then the row becomes permanently "OWNED" (green, non-interactive) — matches the source's "Extra Recruit Slot (Owned)" behaviour.
  • Items are repeatable purchases: each click deducts gold and re-enables immediately, gated only by `gold >= cost` (row dims and un-clicks itself when unaffordable).
  • Relics currency is shown but not spendable in this mock — flag if any shop row should cost relics instead of/alongside gold.
