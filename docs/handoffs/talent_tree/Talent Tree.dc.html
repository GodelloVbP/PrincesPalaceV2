WHAT CHANGED VS THE BUTTON GRID

  • Six flat columns of identical rectangles became a rooted, branching vine tree — a hero crest at the root, six limbs fanning upward, each ending in a capstone keystone. Structure now teaches itself: bottom-up progression, top = payoff.
  • Hover any node to see its name, point cost, and effect in a dedicated info panel — nothing was previously explained without leaving the screen.
  • Point cost is a visible badge on every node (1pt/2pt/3pt), and invested state is a filled gold medallion + checkmark instead of a colour you had to compare across 30 near-identical buttons.
  • Locked nodes are visibly dim and disconnected — the connecting vine only lights up gold once the prerequisite below it is invested, so "what do I need first" reads directly off the tree.
  • Added a hero switcher (top-left tabs) so party members share one screen instead of needing a separate menu per hero.

FOR THE ENGINE

  • Each branch is a strict chain: tier4 (bottom, cheapest) → tier0 (top, keystone, 3pt). A node is investable only once the node directly below it in its branch is invested; the root is always "invested."
  • Un-investing is only allowed on the topmost invested node per branch (nothing above it invested) — keeps the chain always valid, same rule Respec exploits (clears everything at once).
  • Cross-links between adjacent branches at the tier-2 row are decorative in this mock (no shared prerequisite) — flag if you want them to gate each other for real.
  • Node states: locked (grey, 55% opacity), available (dim gold outline, pulsing beacon), invested (full gold fill + purple rim + check). Vine segments switch from muted grey-purple to lit gold the moment their lower node is invested.
