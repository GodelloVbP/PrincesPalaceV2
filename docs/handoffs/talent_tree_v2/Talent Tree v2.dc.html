STRUCTURE

  • Three paths sit in their own column and never intertwine with each other. Each totals 21 points (63 total) — orbs default to 1pt each but can be set higher per orb, the system supports mixed costs. All three paths share the same skeleton, just with different names and stat grants.
  • Every path starts as a 3×3 root grid — three roots, each climbing three rings — and all nine feed into one first convergence where the trunk becomes a single point. From there it branches into three limbs (left, center, right) that grow independently, and all three feed into a second convergence at the capstone — any one limb you finish earns it.
  • The glowing orange line lights up orb-by-orb as you invest — at either convergence, only the road you actually took lights up.
  • Investing needs a prerequisite orb lit (either road, at a convergence) and a point remaining; refunding only works on the topmost invested orb in a chain, same rule Respec All exploits.

FOR THE ENGINE

  • Orb cost is per-node and defaults to 1pt, but the field supports any value — set an individual orb's cost higher and spend/remaining totals adjust automatically.
  • Both convergence orbs — the mid-trunk one and the capstone — list multiple parent orbs ("any one of these"), not a strict single chain, so any completed root or any completed limb unlocks it. The mid-trunk convergence additionally requires 8 points already spent in the path; the capstone requires 20.
  • "Can this be un-invested" is still just "does nothing below it in the chain depend on it" — applied per orb, checked against every orb that lists it as a parent (including all parents of a convergence).
  • Node sizing marks role, not cost: capstone largest, convergence orbs slightly larger — sizing is independent of the orb's point cost.
