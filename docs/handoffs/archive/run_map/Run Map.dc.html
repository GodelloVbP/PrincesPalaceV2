WHAT CHANGED VS THE BLOCK MAP

  • Every node is now the same painted forest clearing — five trees, no colour block. Room type reads from a foreground silhouette: nothing for a plain forest room, a snarling face for a fight, a campfire, a chest, a violet rune.
  • Threat scales the same face: bigger, spikier, angrier for elite, and a full crown + aura for boss — one asset family instead of five icons.
  • State (locked / reachable / walked / current) is a CSS-filter tint on the whole tile — desaturated and dim when closed, full colour and beaconed when open, warm gold-current when you're standing on it. No separate art per state.
  • Edges are a dirt trail, not a line: a wide brown tread with a lighter dashed centreline, gently curved. Walked = packed gold dirt, open = bright tan, ahead/closed fade into the underbrush.
  • Every 8th room caps the branch as Elite, every 16th as Boss — the floor loops; the right edge fades into fog to signal it keeps going.

FOR THE ENGINE

  • One backdrop sprite (clearing_forest, 120×150) shared by every node. Foreground overlay is a second sprite from a small set: mob_face, elite_face, boss_face, campfire, chest, rune; plain forest rooms use none.
  • Room state is a material tint/desaturation pass on the whole node prefab, not separate art: closed ≈ 50% grey + 55% brightness, ahead ≈ 85% brightness, open = full colour + pulsing halo sprite, current = +20% brightness and gold rim glow.
  • Trail is a 9-sliced or spline-rendered ribbon (wide brown base + tan dashed tread strip) following the same control points as today's edge lines — swap the straight Image quad for a LineRenderer/spline with a dirt texture and it inherits all current state colouring.
  • Cadence rule: roomIndex % 16 === 0 → boss, else roomIndex % 8 === 0 → elite, else roll forest/mob/rest/shop/event. This map shows two cycles (rooms 1–16); the map generator repeats the pattern indefinitely and the view just scrolls.
