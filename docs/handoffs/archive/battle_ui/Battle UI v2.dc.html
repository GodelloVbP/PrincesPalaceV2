THE NESTING MODEL (unchanged)

  • Three depths, always: verb → choice → target. ATTACK skips depth 2; RUN/HOLD BACK resolve immediately. Deepest path is three clicks.
  • The detail panel is the persistent third column while browsing — but now exits at Target depth (rework decision, §1) so nothing sits between the player and the enemy's feet while aiming.
  • Group-target skills now route through Target depth too: every valid plate's reticle lights, any plate confirms. No more instant-resolve AoE misclicks.
  • Hovering a melee skill (Shear, Strike) dims unreachable back-row plates and reticles — teaches the front-rank rule without a word of copy.

NEW: ENEMY & PARTY SYSTEMS

  • Break meter — amber tick row under an elite/boss's HP bar. At full: BROKEN pill, cracked initiative chip, amber flash on the plate.
  • Status pills replace the old joined tag line — border colour is the category (red harm / green benefit / blue control / amber special), text is a 2-letter code until glyph art lands.
  • Roster mini-plates stack above the party plate for the two characters not acting — information only, no swap mechanic.
  • Transformation strip, Brave pips, Second Life dot — the three domain systems with no prior UI surface, all docked on the existing party plate frame.
  • Turn-order ghost — hovering Frost Flare (a push-back effect) previews the reorder directly in the initiative tracker.

COMBAT FEEL (static reference)

−84 +120 MISS −41 ▲ −18 POISON
  • Semantic triad kept (red damage / green heal / grey miss); effectiveness reads as scale + chevron, never a new colour.
  • Poison detonation gets the one new palette token (poison-violet, #b168e8) and its own oversized popup — the only combo with unique feedback.
  • No blur, anywhere. Low-HP state (toggle it above) is a sustained red vignette instead — try it against the HP-contrast fixture before shipping.
  • Shake stays on the stage racks, never the camera or this HUD.
