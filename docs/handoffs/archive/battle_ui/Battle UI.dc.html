THE NESTING MODEL

  • Three depths, always: verb → choice → target. Columns open rightward and the previous column stays visible and dimmed, so the player never loses the thread. The breadcrumb under the root column names the current depth.
  • ATTACK skips depth 2 and goes straight to targeting. SKILL and ITEM open a list; RUN and HOLD BACK resolve immediately. So the deepest path is three clicks and the shallowest is one.
  • Depth 3 highlights the enemy plates on the right rather than drawing a fourth column — the target list already exists on screen, so reusing it keeps the eye where the action is.
  • The detail panel is the third column, not a hover tooltip: it stays put while you arrow through options, so comparing two skills doesn't require re-hovering.
  • MP preview — hovering a skill draws its cost as a lighter segment at the end of the MP bar, so cost is legible in the resource, not just as a number.

WHAT I FIXED FROM THE SCREENSHOT

  • The floating text overlays (> Sheep: HP…, Health Potions: 2, enemy HP printed twice) are gone. Party state lives in one framed plate bottom-left; item counts live inside the ITEM submenu where they're relevant.
  • The skill row previously sat above the verb row and overlapped the hero's HP text. Submenus now open to the side of their parent, so nothing ever covers the battlefield centre or the sprites.
  • Five equal-weight gold buttons gave no hierarchy. ATTACK is the loud one, SKILL/ITEM are neutral, RUN and HOLD BACK are quiet and set apart — the read order matches how often each is used.
  • Enemy HP is now a plate per enemy with a bar and status tags, aligned right against the enemy group, and it doubles as the target picker.
  • Wool reads as 16 pips instead of "3/16" — a charge meter you can see fill without reading.

FOR THE ENGINE

  • Four panel sprites total: panel_gold (party, primary verb), panel_violet (submenu, detail), panel_red (enemy plate), row_hover. Everything else is border tint + text colour.
  • Column geometry: root 300w, rows 52h/gap 10; submenu 404w, rows 66h/gap 8; detail 340w. All bottom-aligned at y=40 so a longer list grows upward and never collides with the dialogue bar.
  • Every row is one Button with a child layout — hover 105%/press 95% still applies. Keyboard: up/down within a column, right/enter to descend, esc to ascend; the same three states drive gamepad.
  • Unaffordable rows keep their glyph and name but lose the cost colour and go 45% — never hidden, so the player learns what exists.
  • Turn timeline is one 78² chip sprite; the acting chip gets the gold frame and the NOW label. Downstream chips scale 0.82 to make the current turn unmistakable.
