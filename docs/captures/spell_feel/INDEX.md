## 1.5x battle speed

Not captured. `FightBeatPlayer.BeatSpeedMultiplier` (static, default 1) is the speed seam, but `SpellRuntimeCaptureTests` only reads `PP_RUNTIME_SPELL` and `PP_RUNTIME_VERSUS`, and resets the multiplier to 1 in setup and teardown. A 1.5x capture needs a test change (new env var), so it was skipped.
